FinanceVision — Dashboard de Análise Financeira

Sobre o projeto

O FinanceVision é um projeto de análise de dados financeiros desenvolvido para transformar registros de receitas e despesas em informações visuais que auxiliam na tomada de decisões.

O projeto utiliza uma base de dados fictícia com 5.000 lançamentos financeiros, armazenada no MySQL e conectada ao Power BI.

Tecnologias utilizadas

- Power BI: desenvolvimento dos dashboards e visualizações interativas.
- MySQL: armazenamento e organização dos dados financeiros.
- SQL: criação e consulta da base de dados.
- DAX: criação de medidas e indicadores financeiros.

Funcionalidades

- Análise de receitas e despesas.
- Cálculo do lucro líquido estimado.
- Indicador de margem de lucro.
- Evolução mensal de receitas e despesas.
- Análise de despesas por categoria.
- Distribuição percentual de receitas e despesas.
- Comparação de indicadores financeiros.
- Filtros interativos por período e departamento.
- Navegação entre as páginas Visão Geral e Análise Detalhada.

Objetivo

Demonstrar conhecimentos práticos em análise de dados, modelagem de informações financeiras, criação de medidas DAX e desenvolvimento de dashboards para acompanhamento de indicadores de desempenho.
